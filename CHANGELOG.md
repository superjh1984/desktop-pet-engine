# Changelog

## 1.1.0 — 2026-07-30

### Added

- Optional, configuration-driven system cursor themes through a separately
  installed copy of Mousecape.
- Persistent base-theme selection and optional per-action cursor switching.
- Bilingual cursor menus, error messages, setup documentation, and manifest
  validation.
- A standard-library Python generator for two original Blob `.cape` demo
  themes; private showcase cursor artwork remains outside the public project.
- Cursor-theme validation in the Universal 2 build check.

### Changed

- Updated the app bundle version to 1.1.0 (build 2).
- Documented Mousecape's separate private-API and non-commercial dependency
  boundary.

## 1.0.0 — 2026-07-22

- Initial public macOS desktop-pet engine, Blob demo assets, asset pipeline,
  Universal 2 build scripts, and reusable Codex skill.
